# Sistema de Gestión de E-commerce

## Descripción
Sistema básico de gestión de comercio electrónico desarrollado en Go (Golang). Permite administrar productos, clientes, inventario y pedidos mediante un menú interactivo en consola.

## Objetivo
Desarrollar una aplicación que facilite la administración de las operaciones básicas de una tienda virtual.

## Módulos
- **Productos:** registrar, listar y buscar productos.
- **Inventario:** consultar y actualizar existencias.
- **Clientes:** registrar y listar clientes.
- **Pedidos:** generar pedidos, calcular totales y consultar el historial.

## Tecnologías utilizadas
- Lenguaje: Go (Golang).
- Editor: Visual Studio Code.
- Control de versiones: Git y GitHub.

## Paquetes utilizados
- fmt
- bufio
- os
- strconv
- strings

## Requisitos
Tener instalado Go en el equipo.

## Ejecución
1. Descargar o clonar el repositorio.
2. Abrir la carpeta del proyecto en Visual Studio Code.
3. Ejecutar el siguiente comando:

```bash
go run .
```

4. Utilizar el menú para administrar productos, clientes, inventario y pedidos.

## Alcance
Aplicación básica de consola con almacenamiento temporal en memoria. No utiliza base de datos ni procesa pagos reales.
